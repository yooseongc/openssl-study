이 페이지와 학습실은 같은 스타일시트를 사용합니다. 중앙 작업 공간, 왼쪽 교재 내부 스크롤, 창 높이에 맞춘 실습 패널을 기본으로 유지합니다.

01. 배치와 스크롤

기본 원칙

  • 학습실은 창 높이 안에 들어오며 페이지 전체는 스크롤하지 않습니다.
  • 교재는 왼쪽 패널 안에서 스크롤합니다.
  • 오른쪽 실습은 sticky 없이 남은 높이를 채웁니다.
  • 교재와 실습을 나란히 묶어 중앙 정렬합니다. 묶음은 페이지 폭의 94%로 창과 함께 자동 확장됩니다.
  • 좁은 화면에서는 교재 / 실습으로 전환합니다.
  • 코드와 실행 결과 사이의 경계는 드래그 또는 방향키로 조절합니다. 인자 안내는 파일별로 제공하고 결과는 같은 파일의 최근 두 번을 비교합니다.
  • 편집기 최대화 버튼은 같은 편집기를 브라우저 전체 높이의 dialog로 확장합니다. 원래 크기 버튼 또는 Escape로 복귀하며 문서·실행 인자·실행 결과를 보존합니다. 결과 경계는 0%까지 줄여 코드 영역을 모두 사용할 수 있습니다.
  • 목차는 닫을 수 있는 dialog로 제공합니다.
  • 코드 편집기에서는 파일 선택과 저장·실행 도구 사이의 남은 높이를 소스에 배분합니다. 줄 번호와 C/C++ 구문 강조를 표시하며 긴 줄은 편집기 안에서 가로로 스크롤합니다.

04. API 카드 표준

EVP_MD_fetch(libctx, algorithm, properties)

역할과 흐름
이름과 속성 조건에 맞는 해시 구현을 가져옵니다. 이 구현으로 연산 컨텍스트를 초기화한 다음 입력을 처리합니다.
인자
알고리즘 이름과 구현 선택 조건을 전달합니다.
소유권 / 수명
반환한 객체는 호출자가 해제할 책임이 있습니다.
반환값
성공 시 포인터, 실패 시 nullptr입니다.
실패 시
이후 연산을 진행하지 않고 실패 원인을 확인합니다.

새 API 설명도 역할과 호출 흐름을 먼저 설명하고 인자·소유권·반환값·실패 경로를 이어서 설명합니다. 색상만으로 성공과 실패를 전달하지 않습니다.

05. 유지 규칙

각 레슨은 개념 해설 전에 필요한 용어의 이름·뜻·사용 맥락을 펼쳐 보여줍니다. 용어 설명 버튼으로 돌아갈 수 있고 목차에서 용어로 검색할 수 있습니다.

구현 기준은 app/static/style.css, 문서 기준은 프로젝트의 STYLE_GUIDE.md입니다. 공통 토큰을 먼저 수정하고 임시 덮어쓰기나 inline style을 누적하지 않습니다.
